# 문자열 덧셈 계산기


## 프로그램 개요

덧셈 계산기

특정 구분자로 구분된 숫자들을 모두 더하는 계산기 프로그램이다. 또한 사용자는 커스텀 구분자를 지정할 수도 있다. 규칙에 존재하는 구분자들로만 숫자들을 더하여 출력해준다.

## 기능 리스트

### 사용자 입력

- 문자열 입력
> ex) 덧셈할 문자열을 입력해 주세요.
  - 숫자와 문자가 조합된 문자열을 입력합니다.
  - ex) "1,2:3", "//;\n1;2;3"


- 입력 유효성 검증
  - 문자열의 유효성을 검증한다.
    1. 음수가 들어올 경우 예외 처리
    2. 구분자가 아닌 문자가 포함될 경우 예외 처리
    3. 구분자 사이에 숫자가 없을 경우 0으로 처리


- 커스텀 구분자 추출 기능
  - "//" 와 "\n" 사이에 있는 문자 또는 문자열을 커스텀 구분자로 설정해준다.
    1. 커스텀 구분자는 없거나, 한 번, 여러 번 모두 가능하다.
    2. 여러 글자가 될 수 있다.

- Parser
  - 문자열을 구분자로 나눠서 숫자들로 되돌려준다.
  

- 덧셈 기능
  - 입력된 양의 숫자들을 더해준다.
  - 숫자로 반환한다.


- 출력 기능
> ex)  결과 : 6
  - 문자열들을 더한 결과를 출력한다.
